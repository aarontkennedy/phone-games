# Phone Games

Offline PWA of personal games (no server, no ads, no accounts). Vite + TypeScript, no framework.

## Standards (read before changing anything)

- docs/TESTING.md: 95% coverage on every metric, enforced. Never lower thresholds. Pure `logic.ts` + thin `index.ts` per game; inject `rng`; fake timers.
- docs/DESIGN.md: use tokens and shared components in src/style.css and src/core/ui.ts; light and dark; 44px targets; 26px min grid cells; 18px min text; contrast tests for every text color pair.
- **Flat design (required):** a minimalist style that uses two-dimensional (2D) shapes, solid colors and clean lines, with zero realistic textures, shadows or gradients. It contrasts directly with realistic styles. In practice:
  - No gradients, `box-shadow`, `text-shadow`, `filter`, `backdrop-filter`, bevels, glows, 3D effects or `url()` textures.
  - Icons are inline SVG with solid fills (src/games/icons.ts). The app icon is generated by scripts/make-icons.mjs.
  - Don't add emoji, because they aren't flat. Use flat SVG icons.
  - Enforced by src/design.test.ts and src/games/index.test.ts. Details are in docs/DESIGN.md.
- **Readable without reading glasses (required):** the player needs reading glasses for small text. All text is at least 18px, and body text is 20px. Use the `--text-*` tokens. Never hard-code a `font-size`, and never shrink text to make something fit: wrap it, shorten it, or simplify the layout. Board numbers must be at least 18px on a 390px-wide phone. Enforced by src/design.test.ts and the E2E `expectReadableText()` helper. Details are in docs/DESIGN.md.
- docs/LEGAL.md: generic game names only (e.g. "Mines", not "Minesweeper"); permissive licenses only; no copied code or assets; shipped third-party code listed in public/THIRD_PARTY_NOTICES.txt.

## Commands

- `npm test`: vitest with coverage thresholds
- `npm run test:e2e`: Playwright, iPhone (WebKit) and Android (Chromium) projects, including offline
- `npm run licenses`: dependency license allowlist
- `npm run check`: all of the above plus tsc

## Notes

- In a sandboxed session, npm network installs can fail. Ask the user to run `npm install` themselves.
- Each game is lazy-loaded from src/games/index.ts and must implement `mount(container) => cleanup`.
