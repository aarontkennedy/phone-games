# Legal standards

Practical rules to keep everything in this app safe to use and publish.
These are conservative guidelines, not legal advice.

## The four kinds of protection

| What | Protected by | Our rule |
|---|---|---|
| Game rules and mechanics (how chess or Hearts plays) | Generally **not** protectable by copyright | Free to implement any classic game. |
| Code, artwork, sounds, fonts, written text | **Copyright** | Use only what we create, or permissively licensed code (see below). |
| Game and product names, logos | **Trademark** | Use generic names (table below). |
| A product's distinctive look and feel | **Trade dress** / copyright in visual expression | Design our own look. Never copy another app's screens, colors, or art. |

## Names

Visible text (titles, descriptions, in-game copy) must use generic names. The test
`src/games/index.test.ts` fails if a game title or description contains a name on its
protected list. Add to that list when you learn of a new one.

| Game | Use | Avoid |
|---|---|---|
| 2048 | 2048 | Threes |
| Minesweeper | Mines | Minesweeper |
| Klondike solitaire | Solitaire, Klondike | Microsoft Solitaire |
| FreeCell | Free Cells | FreeCell |
| Yahtzee | Yacht, Five Dice | Yahtzee |
| Sudoku | Number Place | Sudoku |
| Chess, Checkers, Cribbage, Blackjack, Spades, Hearts, Euchre, Dominoes, Gin Rummy | Same. These are generic. | Brand names of specific apps |
| Falling-block puzzles | Don't build one | Tetris (its owners actively enforce its look and name) |

## Code and dependencies

- **Allowed licenses:** MIT, MIT-0, ISC, BSD-2/3-Clause, Apache-2.0, 0BSD, CC0, Unlicense,
  BlueOak, Python-2.0. `npm run licenses` checks every installed package, and CI runs it
  on every push.
- **Never:** GPL, AGPL, LGPL, MPL, SSPL, "non-commercial" (CC-BY-NC), or no license
  at all. For example, the Stockfish chess engine is GPL, so we can't use it. chess.js
  (BSD-2) is fine.
- **Exceptions** go in `EXCEPTIONS` in `scripts/check-licenses.mjs`, with a reason.
  Only build and test tools can be exceptions, never code that ships to the phone.
- **Code that ships to the phone** (anything bundled into `dist/`) must also be listed,
  with its license text, in `public/THIRD_PARTY_NOTICES.txt`. Right now that's only
  Workbox, which provides offline support.
- **Don't paste code** from other projects, blogs or Stack Overflow. Stack Overflow
  posts are CC-BY-SA, which has share-alike terms. Write it fresh.

## Assets (images, sounds, fonts)

- **Images:** draw everything in code (CSS, SVG, canvas) or generate it with a script in
  `scripts/` (e.g. `make-icons.mjs`). This includes playing cards: card faces use
  standard pips and our own simple court-card designs, never artwork from a commercial
  deck.
- **Fonts:** the phone's system fonts only.
- **Emoji:** the phone's own emoji font draws them. Don't bundle an emoji image set,
  because those carry their own licenses (e.g. Twemoji is CC-BY).
- **Sounds:** synthesize them with the Web Audio API in code.
- **Anything else** must be CC0 or created by you, logged in the table below with its
  source.

| Asset | Source | License |
|---|---|---|
| App icons (`public/icons/*`) | Generated by `scripts/make-icons.mjs` | Ours |
| Game card icons | Inline SVG in `src/games/icons.ts` | Ours |

## Our own code

The repository is public, which GitHub Pages on a free plan requires. `LICENSE`
reserves all rights. GitHub's terms still allow other users to view and fork public
repositories on GitHub, but nothing else.

## Privacy

The app makes no network requests besides loading itself, and has no analytics or
tracking. Everything stays in the phone's local storage.
